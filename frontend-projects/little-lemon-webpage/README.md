# Little Lemon Restaurant – Static Webpage  
[Live Demo](https://naveenx03.github.io/little-lemon-webpage/)

---

## 🎯 Project Overview  
This is a static landing page for *Little Lemon Restaurant*, built using HTML and CSS and deployed via GitHub Pages.  
The webpage highlights the restaurant’s menu, booking information, opening hours, and promotional offer.

---

## 🧰 Features  
- Responsive layout optimized for desktop and mobile  
- A hero section showcasing a promotional offer (“30% off this weekend”)  
- Menu section with images and bold descriptions  
- Booking section with call-to-action to reserve a table  
- Opening hours clearly listed for weekdays and weekends  
- Footer with social media links and copyright notice  
- Easy to deploy via GitHub Pages

---

## 🛠️ Technologies Used  
- HTML5  
- CSS3  
- GitHub Pages (for deployment)
