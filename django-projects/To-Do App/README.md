# 📝 Django To-Do App

A simple Django-based To-Do application that allows users to create, update, and delete tasks.

## 🚀 Features
- Add new tasks  
- Mark tasks as completed  
- Update existing tasks  
- Delete tasks  
- Clean Django MVC (MVT) architecture  
- Uses Django Models, Forms, and Views  

## 🗄️ Database Schema

### **Task Table**
| Field      | Type            | Description               |
|------------|-----------------|---------------------------|
| id         | AutoField (PK)  | Unique task identifier    |
| title      | CharField(200)  | Title of the task         |
| completed  | BooleanField    | Task completion status    |

## 🛠️ Technologies Used
- **Python 3**  
- **Django Framework**  
- **HTML (Templates)**  
- **SQLite (Default)**
